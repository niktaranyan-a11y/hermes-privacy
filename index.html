Hermes — Privacy Policy

Last updated: 14 November 2026

Hermes is a personal desktop assistant application used by a single person — its owner — to work with their own Google account. It is not a public or commercial service: no accounts are offered to third parties and no data of other users is collected.

1. What the application does

Hermes runs locally on the owner's computer. When the owner explicitly asks it to perform a task, it may use the Google APIs the owner has authorised to read, search, create or send items in the owner's own Google account. Typical tasks: finding an email and its attachments, drafting and sending a message, reading or editing a document or spreadsheet, checking a calendar, pulling a file from Google Drive.

The application acts only on the owner's instruction. It does not run background data collection, does not build profiles, and does not monitor the account when not asked to.

2. Google user data accessed

Depending on the task, the application may access:

  • Gmail — read, compose, send and modify messages and attachments (scopes gmail.readonly, gmail.send, gmail.modify);
  • Google Drive — list, read, download and upload files (scope drive);
  • Google Docs and Sheets — read and edit documents and spreadsheets (scopes documents, spreadsheets);
  • Google Calendar — read and create events (scope calendar);
  • Google Contacts — read-only address book lookup (scope contacts.readonly).

Only the data needed for the specific task the owner requested is accessed.

3. How the data is used and stored

Data is used solely to carry out the owner's request on the owner's own machine. Nothing is sent to a server operated by the developer of this application — there is no such server.

OAuth credentials (access and refresh tokens) are stored in a local file on the owner's computer (%LOCALAPPDATA%\hermes\google_token.json) protected by the operating system's user account permissions. Copies of documents, emails or other content are kept only in local working folders while a task is being performed, and are deleted when no longer needed.

Language-model processing of task text happens through the assistant's configured model provider; only the minimum text required for the task is sent, and Google account credentials are never transmitted to it.

4. Sharing and disclosure

The application does not sell, rent, trade or otherwise share Google user data with any third party. Data is not used for advertising, profiling, creditworthiness or lending purposes, and is not read by humans except where the owner themself reads it.

5. Limited Use disclosure

Hermes' use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.

6. Retention and deletion

Tokens are retained until the owner revokes access or deletes the local file. Access can be revoked at any time at myaccount.google.com/permissions; deleting google_token.json removes all stored credentials from the computer. Locally saved working copies of documents and messages can be deleted by the owner at any time.

7. Security

Access is protected by OAuth 2.0; the application never receives the owner's Google password. Tokens are stored locally, never published, and transmitted only over HTTPS to Google's own endpoints.

8. Children

The application is not directed to children and is not offered to anyone other than its owner.
